## First: visible entry points, explicit setup

Separate editor capability from configured/consented AI activity. Existing Word sparkle/context/search/ribbon remain visible when its toolset is available; isActive still means usable transport. Mini-toolbar/context clicks, title search Ask and Elixir Ask/Alt+I route to one setup assistant when unconfigured. They do not probe selection, construct a toolset, queue an auto-submitted instruction or issue a provider request. Ordinary command search keeps its ordering/Enter behavior. Slash suggestions stay gated until configured. Spreadsheet support follows its actual toolset in task2; no presentation capability is invented.

The assistant is one short screen with: what selected/relevant document context a later deliberate request sends and to which configured service; provider choice; HTTPS OpenAI-compatible endpoint, model and password-masked key; Continue and Cancel. Start with generic service and empty endpoint/model/key. A separate bounded/validated provider catalog can be supplied by the deployment, with no selected provider/default endpoint/model or hardcoded recommendation. Catalog rendering never probes endpoints. No Ollama discovery, automatic connection test, telemetry or request on setup. Cancel/invalid values preserve previous settings. Repeated entry actions reuse one dialog.

Continue uses the existing Settings.save/native bridge, which opens the native destination disclosure and explicit Allow/Cancel dialog before storing configuration. Desktop keys remain safeStorage-encrypted, are not returned to renderer, journal or plaintext settings; no transport/network policy changes. Refusing consent keeps AI off and the assistant available. Completion does not send a remembered prompt: the user explicitly asks again. Existing configured paths remain unchanged. Browser mode retains its accurate existing browser-storage disclosure and managed-server contract; it cannot promise OS encryption. Existing File settings remain reachable before configuration and use the same setup route where applicable.

Use the editor's existing AI dialog/theme and SDK focus integration; isolate keyboard events, restore a live invoker, clear key fields and dispose on document teardown. New English strings have a separate Z inventory. Avoid changing sealed production main/pins unless required and separately authorized.

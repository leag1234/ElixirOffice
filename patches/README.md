# patches/

Informational exports (`git format-patch`) of our commits on the upstream repositories and on the Nextcloud connector, for review and for a possible upstream contribution. **They are not applied automatically**: the source of truth is the `elixir/*` branch of the repository concerned (DocumentServer submodule or connector clone).

The text was renamed like the rest of the repository (`tools/rebrand`): the upstream project's names appear in it in their ElixirOffice form. A patch meant for the upstream project is re-exported from the branch, not from these files.

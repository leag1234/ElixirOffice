# Unshipped localized template sources

SPDX-License-Identifier: CC0-1.0

These fictional generated examples are withheld from Home assets because the
standard desktop font pack lacks characters required by their language. They are
not copied by desktop assembly or served from brand/templates. Regenerate them
with tools/desktop/home_templates.py. After a Unicode font-pack update, rerun the
coverage check and regenerate thumbnails before adding their languages to the
shared manifest. Provenance is the public synthetic corpus/provisional layout set.

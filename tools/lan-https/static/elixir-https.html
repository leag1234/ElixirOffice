Installer le certificat du réseau local (une seule fois)

Cette suite bureautique de test est servie en HTTPS par un certificat émis par une autorité locale. Pour que le navigateur la considère comme sûre (et autorise l'accès à vos polices), installez une fois le certificat de cette autorité. Il ne sert qu'à ce serveur de test.

Télécharger elixir-ca.crt

La première fois, le navigateur affiche « Votre connexion n'est pas privée » : c'est normal tant que le certificat n'est pas installé. Cliquez sur Paramètres avancés, puis sur Continuer vers … (dangereux) pour télécharger le certificat, installez-le (ci-dessous), fermez le navigateur et rouvrez l'adresse : le cadenas est alors fermé, sans avertissement.

Windows 10 / 11

  1. Double-cliquez sur elixir-ca.crt (dossier Téléchargements), puis « Ouvrir ».
  2. Cliquez sur Installer le certificat…
  3. Choisissez Utilisateur actuel (ou « Ordinateur local » avec les droits d'administration), puis Suivant.
  4. Cochez Placer tous les certificats dans le magasin suivant, cliquez sur Parcourir et choisissez Autorités de certification racines de confiance. OK, Suivant, Terminer.
  5. Répondez Oui à l'avertissement de sécurité.
  6. Fermez complètement Chrome ou Edge, puis rouvrez-le.

macOS

  1. Double-cliquez sur elixir-ca.crt : le Trousseau d'accès s'ouvre, ajoutez-le au trousseau « Session ».
  2. Double-cliquez sur le certificat ajouté, déroulez « Se fier », choisissez Toujours approuver, fermez (le mot de passe est demandé).
  3. Redémarrez le navigateur.

Ensuite

  1. Ouvrez l'adresse HTTPS donnée (avec Chrome ou Edge) : le cadenas doit être fermé, sans avertissement.
  2. Dans l'éditeur, cliquez sur Utiliser mes polices dans le bandeau, puis Autoriser quand le navigateur demande l'accès aux polices.

Vos polices ne quittent jamais votre ordinateur. Pour retirer le certificat : certmgr.msc (Windows) ou Trousseau d'accès (macOS), supprimez « Caddy Local Authority ».
